# Queen of Change Foundation Website

Official website for Queen of Change Foundation, an NGO dedicated to social development, education, women empowerment, and community welfare.

## Features

* Responsive design
* About Us section
* Mission and Vision
* Programs and Initiatives
* Contact Form
* Donation Information

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Clone the repository:
   git clone https://github.com/Kumari-Sakshi12/ngo-website.git

2. Open `ngo.html` in your browser.

## Project Structure

* `ngo.html` - Main website page
* `ngo.js` - JavaScript functionality
* `README.md` - Project documentation
